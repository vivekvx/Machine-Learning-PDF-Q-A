Offline Research PDF Assistant

Upload a selectable-text PDF. This local app indexes its pages, retrieves evidence, and can ask cached Qwen3-0.6B to answer with source IDs. The optional scratch pointer selects among four short spans for eligible factual questions. It is a separate research model; Qwen was pretrained externally.


The browser sends PDF bytes to this localhost service without making a disk copy. Indexed text stays in memory until removed or the service stops.

Hybrid uses the scratch selector for eligible short fact questions. Paper summaries use the same local Qwen model in both generative modes.

Offline after model setup. PDF text stays on this Mac. Citations show exact extracted excerpts, but a linked passage is not proof that every generated claim is true. No OCR is included. The prior evidence checker is not used.
